# UI 配置・用語ルール（viewer）

## 配置（新機能もこの 4 分類で置き場所を決める）
- ツールバー: モード（ツール）とプロジェクト名のみ
- 3D 左上 view-bar: 見え方（視点・投影・切断・目印）
- 左タブ: 対象（レイヤー）と成果（計測・指摘・差分）
- 右パネル: 今のツールの設定と結果（#props / #tool-opts）。切断中のみ下段に #clip-panel

## 用語
- 座標系は WCS / UCS（Autodesk 系）
- キャンセル系は「キャンセル」、カメラ移動は「〜へ移動」
- 画面に出す単位は「プロジェクト」「版」（コード内部の dataset / Manifest はそのまま）
- データはローカルのみ（要件定義 5.3）。「共有」「全員に反映」系の文言は使わない
